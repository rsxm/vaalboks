# Contribution notes

## Commit messages

Use gitmoji with a short scope in parentheses, followed by a concise
description. Do not use Conventional Commits prefixes such as `feat:`,
`fix:`, or `docs:`.

Examples:

- `✨(share) add folder upload support`
- `🔒(config) disable debug for HTTPS`
- `📝(docs) clarify certificate setup`

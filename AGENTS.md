# Contribution notes

## Commit messages

Use this format:

```text
<gitmoji> [<scope>] <subject>

<optional multi line body>
```

Do not use Conventional Commits prefixes such as `feat:`, `fix:`, or `docs:`.

Examples:

- `✨ [share] add folder upload support`
- `🔒 [config] disable debug for HTTPS`
- `📝 [docs] clarify certificate setup`
